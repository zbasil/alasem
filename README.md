# حاسوب زهراء الكروي — Zahraa Football Supercomputer (النسخة 3.1)

منصة عربية لتحليل وتوقع الدوري الإسباني والدوري الإنجليزي ودوري أبطال أوروبا، مصممة لصناعة المحتوى: شنو مباريات اليوم، شكد احتمال كل نتيجة، ليش الحاسوب
يرجّح فريق، شلون تغيّرت الاحتمالات خلال المباراة، شنو تعني النتيجة للقب وأوروبا والهبوط، وأي قصة تستاهل النشر.

> ماكو موديل يتوقع كرة القدم بدقة كاملة. المضمون هنا: حسابات مفحوصة باختبارات، تقييم أمين على مواسم ما شافها الموديل،
> وكل رقم بالواجهة جاي من ملف بيانات أو تقرير، مع مصدره ووقت تحديثه وإصدار الموديل.


## الجديد بالنسخة 3.1

| | |
|---|---|
| **مباشر للبطولات الثلاث** | نتائج وأحداث وتشكيلات وأرقام من ESPN، مربوطة بأرقام مبارياتنا، مع تصحيحات الـVAR. الاحتمالات المباشرة بموديل inplay-2.0، و«قراءة المباراة» وكل سطر بيها مكتوب نوع دليله. كل رقم وياه عمره. `docs/LIVE.md` |
| **تشغيل ذاتي** | GitHub Actions: المباشر كل 5 دقايق بأوقات المباريات، التحديث الكامل يومياً، النشر على GitHub Pages. بروكسي Cloudflare اختياري للتحديث كل 30 ثانية |
| **مختبر التحقق** | ادعاء + فريقين + فترة ← مدعوم / مرفوض / الأدلة ما تكفي، بالأرقام والمصدر، ونص ريل جاهز. المواجهات السابقة بكل صفحة مباراة. الليغا من 1993/94 والبريميرليغ من 2000/01 |
| **الإنجليزي** | المزيد ← اللغة. الاستوديو يبقى عربي لأنه أداة المحتوى |
| **تطبيق يتثبت** | يتثبت على الموبايل ويشتغل بدون إنترنت، وإشعارات لفرقج المفضلة وقت التطبيق مفتوح |
| **أكثر** | بحث شامل (زر البحث أو `/`)، هدافين البريميرليغ من FPL، ألوان كحلية |

## التشغيل بسرعة

```bash
pip install -r requirements.txt
python -m zsc serve            # افتحي http://127.0.0.1:8000
python -m zsc multi --fetch    # مرة وحدة بعد فك الضغط: ينزّل بيانات البريميرليغ وClubElo (56 MB) من GitHub مجاناً
```

| الأمر | شنو يسوي |
|---|---|
| `python -m zsc serve` | يشغّل التطبيق مع حفظ الإعدادات والقصص وتحدي الجمهور (`data/userdata/`) |
| `python -m zsc update` | تحديث آمن: يجلب المصادر ← يبني البيانات مع 45 فحص ← نسخة جديدة للتطبيق |
| `python -m zsc update --offline` | نفس الشي من الملفات الموجودة بدون إنترنت (بعد إضافة نتيجة يدوياً مثلاً) |
| `python -m zsc export` | نسخة جديدة لبيانات التطبيق من البيانات الحالية (تاخذ معها ملفات البطولتين والمصادر المجانية) |
| `python -m zsc multi [--fetch]` | البريميرليغ ودوري الأبطال: (تحديث مصادر GitHub) ← فحوص ← موديلات ← محاكاة ← ملفات التطبيق |
| `python scripts/free_update.py [--notify]` | المصادر المجانية خارج Claude: ESPN، FPL، Understat، RSS (+ إشعارات ntfy) |
| `python scripts/free_update.py --live` | ملف المباشر بس (ESPN ← `app/data/live/now.json`)، اللي يشغله GitHub كل 5 دقايق |
| `python -m zsc.history` | ملفات المواجهات ومختبر التحقق |
| `python -m zsc status` / `snapshots` / `restore <stamp>` | حالة البيانات، النسخ المحفوظة، والرجوع لنسخة سابقة |
| `python -m zsc evaluate` | التقييم الكامل (حوالي 6 دقائق) ← `reports/evaluation.json` |
| `python scripts/build_app.py` | صفحة وحدة + بياناتها (`dist/web/`) لأي استضافة أو رابط Claude |
| `python -m pytest -q` | كل الاختبارات (Python، ومطابقة حسابات المتصفح عبر Node إذا موجود) |

التفاصيل: [`docs/RUNNING.md`](docs/RUNNING.md).

## الأقسام

| القسم | شنو بيه |
|---|---|
| **اليوم** | مباريات اليوم كبطاقات لوحة نتائج، أوضح مرشح، قصة تستاهل النشر، سباق اللقب والهبوط، أهم المباريات للموسم، دقة الحاسوب |
| **المباريات** | كل الجولات بتوقيت بغداد، النتائج والتوقع الاسترجاعي، فلاتر محفوظة (فرقي، المتابَعة، انتهت، قادمة) |
| **مركز المباراة** | فوز/تعادل/خسارة بمسارين (مدعوم بالسوق / مستقل) ومقارنة SportRadar؛ أسباب الترجيح من مدخلات الموديل؛ أرجح 3 نتائج؛ «شنو تغيّر بالتوقع؟»؛ أثر المباراة على الموسم؛ تبويبات الملخص والملعب والأرقام والأحداث؛ خط زمني تفاعلي؛ «ماذا لو؟» داخل المباراة؛ توقع الجمهور |
| **الفرق** | بطاقة لكل فريق: الفورمة والاتجاه، النتائج مقابل المستوى، الأرض وخارجها، قوة الهجوم والدفاع، المباريات الجاية وصعوبتها وأيام الراحة، فرص الموسم |
| **الموسم** | الترتيب، توقع النهاية (10,000 موسم)، التغييرات مع تمييز ضجيج المحاكاة، «ماذا لو؟» بنتائج من اختيارك، ترتيب المباريات حسب الأهمية، القواعد |
| **الاستوديو** | قصص من الأرقام بدليلها وعينتها، بطاقات PNG (9:16، 4:5، 1:1)، نص فيديو 60–90 ثانية باللهجة العراقية، المحفوظات والملاحظات |
| أزرار إضافية | المنهجية والدقة، البيانات والمصادر (وشنو يحتاج تفعيل)، تحدي الجمهور، أرشيف التحليل العميق (StatsBomb)، اللاعبين (أرشيف 2015/16)، التنبيهات، الإعدادات |
