# البدائل المجانية (النسخة 3)

الطلب كان: كل شي يحتاج مفتاح أو اشتراك، نلقاله بديل مجاني. هذا اللي لقيته وجربته، وشنو صار بكل واحد.

**ثلاث مستويات بالجدول:**

- **شغّال بالتطبيق:** البيانات داخلة بالرابط هسه.
- **محوّل جاهز:** الكود موجود ومختبر على عينات بنفس شكل الردود الحقيقية. يشتغل على جهازج أو على GitHub مجاناً. رابط Claude ما يوصل لهالمواقع، وبيئة الشغل هنا محجوب عنها الإنترنت إلا GitHub.
- **ما ينفع مجاناً:** ماكو بديل مجاني نظيف.

## الكلام اللي ما ينصدق عن «مجاني»

- **API-Football:** خطته المجانية 100 طلب باليوم وكل الخدمات، بس تاريخياً تغطي مواسم سابقة مو الموسم الحالي. تأكدي من لوحتهم قبل ما تعتمدين عليه. المحوّل القديم (`zsc/apifootball.py`) باقي كخيار.
- **football-data.org:** خطته المجانية فيها 12 بطولة، ومن ضمنها الثلاث بطولات، بس النتائج متأخرة وبدون تشكيلات. تحتاج تسجيل مجاني للمفتاح.
- **FotMob وSofaScore:** شروطهم تمنع السحب الآلي ويحجبونه، فما استعملناهم.

## أوامر التشغيل

```bash
python scripts/free_update.py              # ESPN + FPL + Understat + RSS، والنتائج بـoutputs/free ثم app/data/free
python scripts/free_update.py --notify     # + إشعارات ntfy (NTFY_TOPIC بمتغيرات البيئة)
python -m zsc multi --fetch                # البريميرليغ ودوري الأبطال: تحديث مصادر GitHub ثم الموديلات والمحاكاة
python -m zsc export                       # لقطة التطبيق الكاملة؛ تاخذ معها ملفات البطولتين والمصادر المجانية
```

**الاختبارات:** `tests/test_free_sources.py` (6) و`tests/test_multi.py` (5).

**تحديد مهم:** المحوّلات انختبرت على عينات بنفس شكل الردود الحقيقية. ما انجربت على الخوادم نفسها من هنا، لأن بيئة الشغل محجوبة عنها (إلا شكل ردود ESPN وFPL، تأكدت منه بقراءة الموقع).
