## المعرّفات الثابتة

- الفريق: رمز من 3 حروف (`ATM`، `BAR`، `DEP`...) بـ`zsc/registry.py` (48 نادي عبر كل المواسم).
- المباراة: `ESP1-<الموسم>-<المضيف>-<الضيف>` مثل `ESP1-2026-ATM-DEP` (الدوري يلعب كل زوج مرة بكل أرض، فهو فريد).
- المعرّفات الخارجية (SportRadar `sr:sport_event:...`، API-Football fixture id) تنحفظ جنبه بـ`data/standard/external_ids.csv`.
- اللاعب (الأرشيف): اسم StatsBomb الكامل.

## الحقوق والاستخدام

- StatsBomb Open Data: استخدام غير تجاري مع ذكر «Data: StatsBomb» (مكتوب بكل صفحة أرشيف وبالبطاقات).
- football-data.co.uk وopenfootball: بيانات عامة مجانية؛ المصدر مذكور بالواجهة.
- SportRadar: يوصل فقط داخل جلسات Claude؛ الاحتمالات المنشورة تنعرض كمقارنة مع ذكر المصدر.
