# الميزات اللي تحتاج مفتاح أو مصدر، وخطوات تفعيلها

حالة كل ميزة تطلع بصفحة «البيانات والمصادر» بالتطبيق (شغّالة / شغّالة جزئياً / تحتاج مفتاح / تحتاج مصدر). أي زر
لميزة غير مفعّلة يبين حالتها وشنو تحتاج، وما يعرض أرقام وهمية.

> **النسخة 3:** كل ميزة بهالملف إلها هسه بديل مجاني (بدون مفتاح أو دفع): التشكيلات والأحداث من ESPN، إصابات
> البريميرليغ ولاعبيه من FPL، xG من Understat، الأخبار من RSS، الإشعارات من ntfy، والاستضافة والتحديث التلقائي من
> GitHub Pages/Actions. التفاصيل والحالة الحقيقية لكل واحد: [`FREE_SOURCES.md`](FREE_SOURCES.md). الخطوات تحت (API-Football)
> باقية كخيار إضافي بس.

## الطريق المجاني بخمس خطوات

1. حساب GitHub مجاني → مستودع عام جديد → ارفعي مجلد المشروع.
2. Settings → Pages → Source: **GitHub Actions** (الملف `.github/workflows/update.yml` جاهز: تحديث يومي + كل 10 دقايق بأوقات المباريات).
3. (اختياري) نزّلي تطبيق **ntfy** على الموبايل، اختاري اسم topic طويل وعشوائي، واشتركي بيه؛ وبـSettings → Secrets → Actions
   ضيفي `NTFY_TOPIC` بنفس الاسم، وبـ`config/free_sources.json` خلي `ntfy.enabled` = `true` وفرقج بـ`fav_teams` (مثل `BAR`).
4. (اختياري) خلاصات الأخبار: بـ`config/free_sources.json` ← `rss.feeds` حطي الخلاصات اللي تثقين بيها.
5. افتحي رابط GitHub Pages: نفس التطبيق، يتحدث وحده.

## 1. التشكيلات والغيابات — تحتاج مفتاح API-Football

**شنو تضيف:** تشكيلة كل فريق على الملعب (الخطة، الأساسيين بمواقعهم، الاحتياط، المدرب) بتبويب «الملعب»، والغيابات
والمشكوك بمشاركتهم ببطاقة كل فريق.

**الخطوات:**
1. سجلي بـhttps://www.api-football.com/ وخذي المفتاح (المجاني: 100 طلب باليوم؛ التحديث الواحد يستهلك 2 + مباراة لكل تشكيلة).
2. بملف `.env` بجذر المشروع: `API_FOOTBALL_KEY=المفتاح`.
3. بـ`config/settings.json` ← `sources.api_football.enabled` = `true`.
4. `python -m zsc update`: يجلب الجدول والغيابات، والتشكيلات للمباريات اللي تبدي خلال ساعتين (أو انتهت قبل أقل من 3 ساعات).
5. شغليه قبل كل مباراة بساعة (التشكيلات تنعلن قبل البداية بحوالي ساعة).

**ملاحظات:** الكود (`zsc/apifootball.py`) مكتوب على صيغة v3 الموثقة ومختبر على أمثلتها (`tests/test_apifootball.py`)، بس
ما انجرب على الخدمة الحقيقية لأن ماكو مفتاح لحد هسه. التوقع نفسه ما يتأثر بالتشكيلة بعد: حتى ينضاف هالمُدخل للموديل
لازم أول نجمع موسم كامل من التشكيلات ونختبر أثره على مواسم ما شافها الموديل.

## 2. التحليل المباشر دقيقة بدقيقة خارج جلسات Claude — يحتاج مفتاح API-Football

**الحالي:** التحليل بنهاية كل شوط يشتغل من جلسات Claude (SportRadar). **مع المفتاح:** ممكن جلب الأحداث المباشرة
(`/fixtures?live=all`، `/fixtures/events`) من الخادم نفسه كل دقيقة. الهيكل (المعرفات، سجل التوقعات المباشر، الموديل
المباشر، صفحة الأحداث) جاهز؛ يحتاج دالة جلب أحداث بنفس أسلوب `zsc/apifootball.py` ومهمة مجدولة على الخادم.

## 3. xG والخرائط الحرارية للمباريات الحالية — تحتاج مصدر أحداث بإحداثيات

**شنو تضيف:** نفس صفحات الأرشيف (خريطة التسديدات مع xG، اللمسات، شبكة التمرير، المواجهات التكتيكية، تقييم اللاعبين)
لكل مباراة حالية.

**الخيارات:** StatsBomb (تجاري)، Opta/Stats Perform (تجاري)، Wyscout. البيانات المجانية (SportRadar عبر Claude،
API-Football) ما بيها إحداثيات. **التفعيل:** حفظ ملف أحداث المباراة بصيغة StatsBomb بـ`data/raw/statsbomb/events_<id>.json.gz`
وإضافتها لقائمة `MATCHES` بـ`scripts/build_archive.py`، ثم `python scripts/build_archive.py` و`python -m zsc export`.

## 4. تحدي الجمهور المشترك بين المتابعين — يحتاج خادم عام

**الحالي:** بالخادم المحلي: مشترك لكل من يفتح نفس الخادم. برابط Claude: مشترك بين أصحاب صلاحية التعديل (المشاهدين يقرون
بس). بالصفحة الثابتة: محلي بالمتصفح.

**الخطوات لخادم عام:**
1. سيرفر صغير (VPS) أو خدمة مثل Render/Railway/Fly.io: `pip install -r requirements.txt`.
2. `ZSC_HOST=0.0.0.0` و`ZSC_PORT=8000` بـ`.env`، وشغّلي `python -m zsc serve` كخدمة دائمة.
3. خلّي قدامه خادم HTTPS (Caddy أو Nginx) واسم نطاق.
4. مهمة مجدولة (cron) كل ساعة: `python -m zsc update`.
5. قبل الإطلاق: أضيفي حماية بسيطة من السبام لطلبات `/api/challenge` (حد للطلبات لكل IP) وأسماء مستخدمين بسيطة؛
   الخادم الحالي ما بيه تسجيل دخول.

## 5. إشعارات الموبايل — تحتاج خادم عام

التنبيهات (تغيّر كبير بالتوقع، تقارير الأشواط، قصص جديدة) تشتغل هسه داخل التطبيق (الجرس). لإشعارات تطلع والتطبيق مسدود:
خادم عام (البند 4) + Web Push (مفاتيح VAPID) أو بوت تيليغرام/واتساب يرسل نفس التنبيهات. «إعلان التشكيلة» يحتاج البند 1.

## 6. إحصائيات لاعبي الموسم الحالي — تحتاج مصدر

صفحة اللاعبين تشتغل هسه على موسم الليغا 2015/16 كامل (StatsBomb). لموسم 2026/27: API-Football (`/players?league=140&season=2026`)
يعطي أرقام أساسية (دقائق، أهداف، تسديدات، تمريرات مفتاحية، افتكاك...)، بدون xG وxA. التقييم العادل بين المراكز
(`zsc/players.py`) يشتغل على أي جدول بنفس الأعمدة.

## 7. اللغة الإنجليزية — مخطط لها

كل النصوص بالواجهة عربية؛ الأسماء الإنجليزية للفرق موجودة بـ`teams.json`. الإضافة تحتاج ملف ترجمة للنصوص الثابتة
وتبديل اتجاه الصفحة (LTR).

## 8. دوريات أخرى — بالإعدادات

`config/settings.json` (المسابقة والموسم والمنطقة الزمنية) و`config/competitions/<ID>.json` (النقاط، كسر التعادل،
المراكز). تحتاج مصادر نتائج للدوري الجديد وإعادة التقييم الكامل (`python -m zsc evaluate`) قبل نشر أي توقع.
