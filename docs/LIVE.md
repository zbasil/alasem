# البيانات المباشرة (النسخة 3.1)

## شلون توصل النتيجة المباشرة للتطبيق

```
ESPN (مجاني، غير رسمي) ──► GitHub Actions كل 5 دقايق بأوقات المباريات
                           scripts/free_update.py --live
                           zsc/livefeed.py: ربط كل مباراة برقمها عدنا، أحداث بأرقام ثابتة، تصحيحات VAR
                           ──► data/live/now.json (ملف واحد صغير)
                                         ──► كل متابع يقرا نفس الملف (كل دقيقة وقت المباريات، كل 10 دقايق غيرها)
```

- **ولا متصفح يسأل ESPN مباشرة.** الطلب للمصدر يصير مرة وحدة، وكل المتابعين يقرون النسخة نفسها.
- **كل رقم وياه عمره.** التطبيق يكتب «مباشر من ESPN · تحديث قبل X»، ولو صار عمر الملف أكثر من 20 دقيقة يصير «متأخر».
- **التخمين ينكتب تخمين.** لو المباراة بدأت حسب الموعد بس الملف المباشر ما وصل، الحلقة تطلع `~23'` ومكتوب «تقديري».
- **التصحيحات تبقى ظاهرة.** هدف انلغى بالـVAR يطلع مشطوب بالخط الزمني، والنتيجة اللي نزلت تنسجل كتصحيح.
- **المجهول يبقى مجهول.** رقم ما موجود بالمصدر يطلع «—»، مو صفر.

## شكد التأخير الحقيقي

| الطريقة | التأخير المتوقع | الكلفة |
|---|---|---|
| GitHub Actions (المفعّل) | 5 دقايق بالجدول، وGitHub أحياناً يأخر التشغيل المجدول 5–15 دقيقة إضافية بأوقات الضغط | صفر للمستودع العام |
| + بروكسي Cloudflare (اختياري) | حوالي 20–50 ثانية للنتيجة والدقيقة | صفر ضمن الخطة المجانية (100,000 طلب باليوم) |

الأحداث الكاملة (الخط الزمني والتشكيلات والأرقام) تجي من ملف GitHub Actions. البروكسي يحدّث النتيجة والدقيقة والحالة بس.

## تفعيل البروكسي (اختياري، يحتاج حساب Cloudflare مجاني)

1. `cd workers/live-proxy && npx wrangler deploy` (يطلب تسجيل دخول Cloudflare أول مرة).
2. بإعدادات المستودع: Settings ← Secrets and variables ← Actions ← Variables ← `LIVE_PROXY` = رابط الـWorker (`https://zsc-live-proxy.<اسمج>.workers.dev`).
3. التشغيل الجاي يكتب الرابط بملف المباشر، والتطبيق يبدي يقرا منه كل 30 ثانية وقت المباريات بس.

## الإشعارات

| النوع | يشتغل متى | التفعيل |
|---|---|---|
| إشعارات المتصفح (من التطبيق) | التطبيق مفتوح أو بتبويب بالخلفية | المزيد ← إشعارات المباريات المباشرة |
| ntfy (تطبيق موبايل مجاني) | دائماً، حتى والتطبيق مسدود | `NTFY_TOPIC` بـSecrets، و`"enabled": true` لـntfy بـ`config/free_sources.json` |

إشعارات «Web Push» الكاملة وهو مسدود تحتاج خادم يخزن الاشتراكات؛ ntfy يغطيها مجاناً هسه.

## حدود ESPN

- API غير رسمي وللاستعمال الشخصي غير التجاري. لو صار الحساب تجاري، نحتاج مزوّد مرخّص.
- xG ما موجود بـESPN. التطبيق ما يعرض xG مباشر.
- مواقع اللاعبين على الملعب حسب الخطة المعلنة بس، مو بيانات تتبع.
